É a converção que organiza os arquivos do usuário no home


| Sistema (root) | Usuário          | Conteúdo                                                    |
| -------------- | ---------------- | ----------------------------------------------------------- |
| `/usr/bin`     | `~/.local/bin`   | Executáveis                                                 |
| `/usr/share`   | `~/.local/share` | Dados de aplicação (ícones, .desktio, arquivos do programa) |
| `/etc`         | `~/.confg`       | Configurações                                               |
| `/var/cache`   | `~/.cache`       | Cache descartável                                           |
| `/var/lib`     | `~/.local/state` | Estado (Logs, Histórico, Sessão)                            |
