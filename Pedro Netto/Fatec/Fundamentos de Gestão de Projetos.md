### O que é um projeto?
por não haver definição clara de "projeto", mas pode tirar pontos importantes sobre descrição de projeto.

- O Objetivo da atividade é satisfazer as necessidades do cliente
- A Atividade do projeto é um processo de transformação
- O Projeto começa com um conceito e termina na tradução especificação de algo que pode ser reproduzido.

Portanto, projeto pode ser compreendido como um esforço temporário empreendido para criar produtos, serviço ou resultado.

### - Partes do Projeto -
-> Criação
	-> Design
	-> Planejamento
-> Execução
	-> Engenheiro
	-> Cronograma, sprint.

**Projeto nasce do conceito** -> Clientes querem experiência -> Conceito Cativante.

### O Clico de vida de um projeto
-> Segundo o guia **PMBOK** do *Project Manage Institute (PMI)*.
O Clico de vida pode ser dividido em 5 fases:

1. Inicialização
2. Planejamento
3. Execução
4. Controle
5. Encerramento

- Inter-relacionamento de projeto de produto/serviço e projeto de processos.
Embora estudos diferentes, estes dois tipos de projetos na prática estão interconectados, pois pequenas **mudanças no projeto** do produto e serviço podem ter **consequências**, para o modo como a produção deve faze-lo.

Portanto o projeto de processos pode restringir a liberdade do projetista e serviço e produto.

- A sobreposição de projetos
- Por serem inter-conectados, acaba havendo uma sobreposição entre o projeto de produto e produtos de serviços.
	- Porém geralmente esta sobreposição é maior em operações que produzem serviços.

A final, muitos serviços envolvem o cliente fazendo-o tomar parte do serviço,  em termos do que o cliente vê, não pode ser separado do processo no qual o cliente está submetido.

### 4 Aspectos de projeto:
#### **Criatividade**
Criar algo que não exista antes;
"Inovar não é fácil"
		Qual é o ==diferencial==?
	**Exemplo**: "vou vender internet"
		Mas qual vai ser a sua diferença entre várias provedoras?.
		Vai conceder assinaturas Netflix para um plano de internet específico.
#### **Complexidade**
Tomar decisões sobre grandes números de variáveis.
"Explicar ferramentas e tecnologias"
#### **Compromisso**
Balancear "**Desempenho x Custo**"
	Para não "*Matar uma formiga com uma bazuca*"
#### **Escolha**
Fazer escolhas entre diversas soluções possíveis para um problema em todos os níveis desde o conceito básico até o menor detalhe.
"Entre tecnologias, qual é a melhor para o projeto?"
"Entre os profissionais, qual se adapta ao serviço?"

---
#### **Projeto de Produtos e Serviços**
3 Etapas de um projeto - do conceito à especificação
Após a coleta de informações o resultado da atividade de projeto é a especificação detalhada, onde é definido o produto ou serviço.

- **Conceito Global**
	Especificando a forma, a função e o objetivo global do projeto e os seus benefícios.
- **Seu pacte**
	Especificar todo o conjunto de produtos e serviços individuais que são necessários para reparar e apoiar o conceito.
- **Processo pelo qual será criado**
	Especificando como os vários produtos e serviços individuais no pacote devem ser produzidos.

### Pert
Ele entra quando não temos certeza de quanto tempo uma tarefa vai levar.
Em vez de uma única estimativa, o Pert pede por três: **Otimista, Mais provável e Pessimista**.

#### Calculo de duração esperada
**Otimista** (O): Se tudo der certo, qual o tempo minimo.
**Mais provável** (M): Qual tempo realista.
**Pessimista** (P): Se der errado, qual o tempo máximo?

Fórmula:
`Te = (O + (4xM) + P)/6`
