O [[1.1 - Nó de controle|Control Node]] utiliza um **inventário**, que é um arquivo de texto com uma lista configurável de **hosts alvos** do [[Ansible]], essa lista é em formato '[[INI]] ou [[YAML]]'.

Sendo possível organizar os servidores em **grupos**.
```bash
$cat inventory.ini 
[fileserver]
192.168.122.145
```
