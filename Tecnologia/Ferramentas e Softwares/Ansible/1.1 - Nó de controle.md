#### Nó de controle
A automação é iniciada no '**Nó de controle** (Control Node), é a máquina (servidor ou computador pessoal) onde o [[Ansible]] está instalado, que deve ser um sistema [[Unix|Unix-Like]] com [[Python]]
> **Obs**: no [[Windows|Ruimdows]], só é executado via [[WSL]]

Conectando utilizando o [[SSH]], para a instalação inicial e gerenciamento básico de nós
