**IOMMU (Input-Output Memory Management Unit)** no [[Linux]]
é um componente de [[Hardware]] (como [[Intel VT-d]] ou [[AMD-Vi]]) que mapeia endereços virtuais de dispositivos I/O para endereços físicos, permitindo isolamento seguro de memória e acesso direto ([[DMA]]). 

Essencial para #virtualização, ele possibilita que [[Máquinas virtuais (VMs)]]controlem hardware físico (passagem PCI/GPU) com segurança
