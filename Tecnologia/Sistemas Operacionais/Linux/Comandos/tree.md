Traduzindo literalmente, é 'Árvore' ou seja, uma Árvore apresenta seu tronco, porém ela também possui raízes, então ao utilizar esse comando, ele exibe as pastas e suas raizes.

é um utilitário [[Linux]]/[[Unix]] para apresentar as pastas e subpastas do Linux

para instala-lo utilizamos:
```
sudo apt install tree
```

e para utilizar ele, podemos executar: `tree`
assim exibindo as pastas e subpastas

alguns paramêtros:
- `-a`: lista todos os arquivos (até os ocultos)
- `-d`: lista somente os diretórios
- `-f`: exibe somente o caminho completo dos arquivos
	![[tree-f.png]]
- `-p`: exibe as permissões dos arquivos
	![[tree-p.png]]
- `--help`: exibe as explicações
- `--version`: exibe informações do utilitário
