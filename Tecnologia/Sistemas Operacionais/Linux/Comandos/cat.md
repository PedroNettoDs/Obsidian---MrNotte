O Comando do [[Linux]]:
`cat` vem da abreviação de **concatenate**, 

ele tem funções de:
### Visualizar arquivos:
```bash
cat arquivo.txt
```

### Combinar arquivos:
```bash
cat arquivo1.txt arquivo2.txt
```

### Criar novos arquivos:
```bash
cat > novoarquivo.txt
```

### Visualizar o número de linhas
```bash
cat -n arquivo.txt
```
