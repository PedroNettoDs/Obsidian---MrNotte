Comando [[Unix]]/[[Linux]] usado para criar [[Diretórios|diretórios]] (pastas).
```bash
mkdir <nome da pasta desejada>
```

Assim criando uma a pasta no local que o terminal se encontra ([[Caminho relativo]]), ou no lugar especificado ([[Caminho Absoluto]])
importante compreender os parâmetros do comando.
