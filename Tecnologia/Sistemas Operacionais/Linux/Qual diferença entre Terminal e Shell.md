O [[Terminal]] é a 'interface' para o [[Bash]].

Importante compreender a historia que se passou após lançamento do [[Unix]], os computadores eram muito caros para cada usuário ter o seu, assim então foi elaborada a estratégia de 'Terminais' conectados até o 'Servidor', que no caso seria o Computador com o Unix rodando.

Exemplificação seria o VT100, que foi o um Terminal, que capturava o que você estava digitando e direcionava para o Computador Host: 
![[Diferença Terminal e Shell.png]]
Dessa forma, poderiam vários [[Usuário]]s utilizarem o computador ao mesmo tempo.
