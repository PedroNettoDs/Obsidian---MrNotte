### Sobre
A sendo um [[acrônimo]] de: "**GNU's Not Unix**" = "*GNU não é [[Unix]]*".

É o projeto que fornece as '*ferramentas*' para o [[Linux]]  somente o [[Kernel]].

![[GNU.png | 300]]
>Como assim o Linux é só o Kernel, então quais ferramentas o GNU oferece?

### Ferramentas
O **GNU** oferece ferramentas essenciais, como:
- [[Compilador]]
- [[Biblioteca]]
- Interpretadores de comandos ([[Bash]])
