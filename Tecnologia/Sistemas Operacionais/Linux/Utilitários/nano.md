É um editor de texto para [[Linha de comando|CLI]].

https://medium.com/@habbema/tutorial-do-nano-3e6aec905213

| Command                                    | Description                                               |
| ------------------------------------------ | --------------------------------------------------------- |
| **Ctrl** + **W**                           | Pesquisar no arquivo                                      |
| **Ctrl** + **W**, then **Control** + **R** | Pesquisar e substituir                                    |
| **Ctrl** + **G**                           | Mostra os comandos possíveis                              |
| **Ctrl** + **Y**/**V**                     | Page UP e Down                                            |
| **Ctrl** + **C**                           | show the current position in the file and the file’s size |
