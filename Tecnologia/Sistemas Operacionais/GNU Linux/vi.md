A sigla **VI** significa **V**isual **I**nterface
Ele é um **editor de texto** do sistema operacional [[Linux]]/[[Unix]]
Permitindo salvar sua escrita em arquivos através do [[Linha de comando|CLI]]

| Tecla | Função                                                                      |
| ----- | --------------------------------------------------------------------------- |
| `j`   | Move o cursor uma linha para baixo (mesmo que seta para baixo)              |
| `k`   | Move o cursor uma linha para cima (mesmo que seta para cima)                |
| `l`   | Move o cursor um caractere para a direita (mesmo que seta para a direita)   |
| `h`   | Move o cursor um caractere para a esquerda (mesmo que seta para a esquerda) |
| `w`   | Move o cursor para o início da próxima palavra                              |
| `e`   | Move o cursor para o final da palavra atual                                 |
| `b`   | Move o cursor para o início da palavra anterior                             |

| Recurso                | **[[vi]]** (Original)                               | **[[Vim]]** (Vi Improved)                                              |
| ---------------------- | --------------------------------------------------- | ---------------------------------------------------------------------- |
| **Realce de Sintaxe**  | Não possui (texto em cor única).                    | Colorização automática de códigos (Python, C, HTML, etc.).             |
| **Desfazer / Refazer** | Apenas um nível de `undo`.                          | Múltiplos níveis de `undo` e `redo` (histórico completo).              |
| **Navegação**          | Apenas por comandos de letras (`h`, `j`, `k`, `l`). | Aceita o uso das setas do teclado e do mouse.                          |
| **Extensibilidade**    | Não suporta extensões.                              | Amplo ecossistema de plugins e scripts.                                |
| **Divisão de Telas**   | Não permite.                                        | Divide a tela horizontal ou verticalmente para editar vários arquivos. |
| **Interface Gráfica**  | Apenas via terminal (CLI).                          | Possui versão gráfica dedicada (**gvim**) com menus de mouse.          |
