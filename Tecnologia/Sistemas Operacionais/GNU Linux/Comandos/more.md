No [Linux](app://obsidian.md/Linux)/[Unix](app://obsidian.md/Unix), o comando `more` exibe o conteúdo de forma sequencial
- **Navegação de visualização**
	- Apenas para frente
		- Sendo possível utilizar o **ESPAÇO** para passar para o '*próximo espaço de texto*', quanto o **ENTER** para *passar por linhas*.
- **Limitações**
	para exibir o aquivo, é carregado o arquivo inteiramente na memória, consumindo muita RAM com arquivos grandes
