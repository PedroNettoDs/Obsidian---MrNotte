### Sobre
A extensão de arquivo `.deb` significa "**Pacote Debian**" e é utilizado para realizar instalações de softwares entre as [[Distribuição Linux|Distribuições Linux]] baseadas em [[Debian]].
Sendo equivalente aos arquivos `.exe` instaladores do [[Windows|Ruindows]] 

### Como instalar
Após realizar o download desse arquivo, prosseguimos utilizando o gerenciador de pacotes '[[apt - Advanced Package Tool|apt]]':
```bash
sudo apt install ./<nome_do_pacote>
```
