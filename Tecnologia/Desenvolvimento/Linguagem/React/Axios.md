Axios é uma biblioteca popular de cliente [[HTTP (Hypertext Transfer Protocol)|HTTP]] 
baseada em _promises_ (promessas),

usada no [[React]] para realizar requisições assíncronas (GET, POST, PUT, DELETE) e se comunicar com [[API - Interface de Programação de Aplicações|API]]s externas ou #Backend. 

Ele facilita a manipulação de dados, oferece transformação automática de JSON e interceptação de requisições/respostas

https://axios-http.com/ptbr/docs/intro

**Principais características e vantagens:**

- **Baseado em Promessas:** Suporta `async/await` para um código mais limpo.
- **Isomórfico:** Funciona tanto no navegador quanto no [[Node.js]]
- **Recursos Avançados:** Intercepta requisições e respostas, permitindo adicionar tokens de autenticação facilmente.
- **Facilidade de Uso:** Simplifica o tratamento de erros e a conversão de dados JSON.

---

- **Instalação:** `npm install axios`.
- **Uso:** Importar nos componentes e chamar os métodos (ex: `axios.get('/api/dados')`).
