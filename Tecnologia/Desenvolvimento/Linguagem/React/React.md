### O que é?
é uma biblioteca [[Javascript]] de [[Código aberto]], mantido pelo Facebook (Meta);
Seu foco é criação de interfaces de usuários ([[UI]]) interativas e reativas para aplicações web e móveis.
#Frontend 
Ela utiliza uma arquitetura baseada em 'Componentes' e um 'Virtual DOM' para melhorar a atualização de página.

- Componentização
