**HTML (HyperText Markup Language)**
é a linguagem padrão para estruturar e dar sentido ao conteúdo de páginas web, organizando elementos como textos, títulos, parágrafos, imagens e links. 

É lida por navegadores (Chrome, Firefox) e utiliza tags (ex: <p>, <h1>) para definir a estrutura, mas não é uma linguagem de programação
