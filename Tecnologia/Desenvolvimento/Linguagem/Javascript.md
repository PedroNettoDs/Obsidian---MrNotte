JavaScript é uma linguagem de programação de alto nível, interpretada e voltada a objetos, essencial para criar páginas web interativas e dinâmicas. 
Junto com [[HTML]] e [[CSS]], forma a base da web moderna, permitindo funcionalidades como animações, mapas, atualização de conteúdo sem recarregar a página e validação de formulários
