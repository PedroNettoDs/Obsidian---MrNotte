Gunicorn (Green Unicorn)
é um servidor #Web [[WSGI]] Python de alta performance para sistemas [[Unix]], ideal para colocar aplicações em produção. 

Ele atua como intermediário entre servidores web (como [[Nginx]]) e o [[Framework]] da aplicação (como [[Django|Django]] ou Flask), gerenciando múltiplos processos ("workers") para lidar com requisições simultâneas de forma eficiente
