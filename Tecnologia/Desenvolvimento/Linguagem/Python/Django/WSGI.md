WSGI (Web Server Gateway Interface) é uma especificação padrão que atua como ponte entre servidores web (como [[Nginx]] ou [[Apache]]) e [[Framework]]s web [[Python]] (como [[Django|Django]], Flask). 
Ele define um protocolo uniforme para que servidores e aplicações Python se comuniquem, garantindo portabilidade, eficiência e segurança na implantação de sites
