Python é uma linguagem de programação de alto nível, interpretada, orientada a objetos e de propósito geral, famosa pela sua sintaxe clara e legibilidade, facilitando o aprendizado. Criada por Guido van Rossum em 1991, é amplamente usada em ciência de dados, inteligência artificial, desenvolvimento web e automação, sendo uma das mais populares e versáteis do mercado
