é o [[Gerenciador de Pacotes]] padrão para o [[Node.js]], sendo considerado o maior [[Repositórios]] de software, facilitando instalações, compartilhando e gerenciando dependências em projetos [[Javascript]].

Permitindo baixar [[Biblioteca]]s prontas via [[Linha de comando|CLI]] e organizando o projeto através do arquivo: `package.json`.
