Tal como o atual Discord, possuindo Canais, com os nomes dos canais começando com hashtag

Mensagens Privadas, permitindo bate-papo direto entre dois usuários

Modelo Cliente-Servidor, você usa um programa chamado cliente (como o clássico **mIRC**) para conectar a um servidor da rede
